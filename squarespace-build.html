Building /overloaded in Squarespace

Plan note: Page-level Code Injection requires Squarespace Business plan or higher. If you're on Personal, see Step 6 for the workaround.
1

Create the page

  1. Pages panel → + → Blank Page
  2. Title: Overloaded
  3. URL slug: /overloaded
  4. Set page to Not Linked until ready to launch publicly
2

Paste the override CSS

This is what gives the page its Blue Lake Ideas look — overriding Squarespace's default fonts, colors, and button styles on this page only.

  1. On the new page, click Settings (gear icon)
  2. Open the Advanced tab
  3. In the Page Header Code Injection field, paste the block below — wrapped in <style>...</style> tags
⬇ Download overloaded-overrides.css

View the full CSS at overloaded-overrides.css

4

Apply eyebrow class via Markdown block

For "eyebrow" small-caps labels (like "A NEW BOOK BY MATT ELLIOTT"), the cleanest way is a Markdown block instead of a Text block:

<p class="eyebrow">A New Book by Matt Elliott</p>

The override CSS targets .eyebrow and styles it as uppercase Deep Blue Lake DM Sans.

5

Connect the Newsletter Block to the lead flow

This is what makes the waitlist actually work. Follow Section 06 of the campaign reference:

  • In the Newsletter Block → Storage → connect to Squarespace Email list "Overloaded Waitlist"
  • Squarespace Email auto-sends the welcome (Section 02 of reference)
  • Zapier picks up the submission → creates the HubSpot contact + adds to static list
6

Personal-plan workaround (no Page Header Code Injection)

If Page Header Code Injection isn't available:

  1. Add a Markdown block at the very top of /overloaded with: 
    <script>document.body.classList.add('overloaded-page');</script>
  2. Go to Design → Custom CSS (site-wide)
  3. Paste the override CSS, but wrap every selector with body.overloaded-page at the start

Example:

body.overloaded-page h1 { font-family: 'Libre Baskerville', serif !important; }
body.overloaded-page .sqs-block-button-element { background: #005B54 !important; }

Slightly messier, but only affects /overloaded.

7

Test before publishing

  • Check the page in Preview mode on desktop and mobile
  • Submit a real test signup to confirm Squarespace Email + Zapier + HubSpot all fire
  • Verify the welcome email lands in inbox within 1 minute
  • Confirm the contact appears in HubSpot's Overloaded Waitlist list
  • Then move the page from Not Linked to navigation
