Overloaded Code Blocks

Seven self-contained Code Blocks. Paste each one into a Squarespace Code Block, top to bottom.

How to use this page

  1. On the /overloaded page in Squarespace, click Edit
  2. Add a section → Add a Code Block
  3. Come back here, tap Copy code for Section 1
  4. Paste into the Squarespace Code Block. Make sure Display Source is OFF
  5. Save. The section renders.
  6. Repeat for Sections 2 through 7

Each block is fully self-contained — fonts, colors, layout all included. No Page Header Code Injection needed. They won't conflict with each other or with Squarespace defaults because each uses a unique wrapper class.
