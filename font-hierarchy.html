Section 01

The Two Typefaces

Clear division of labor

Two typefaces. Each does one job. The combination is what makes the brand feel both editorial and modern.

Serif · Display
Libre Baskerville
Display + emotional accent
Headlines, italic subheads, email subject lines, signatures
Sans · Workhorse
DM Sans
Everything else
Body, UI, labels, buttons, eyebrows

Section 03

Universal Rules

Five rules that hold everything together

Line-height scales with size. Body 1.65 · cards 1.55–1.6 · headlines 1.05–1.4.
Letter-spacing scales with case. The smaller and more uppercase, the more tracking (0.16–0.22em).
Bold emphasis is Deep Blue Lake, not black. <strong> tags inside paragraphs use #005B54 for color.
Italic Libre Baskerville is the "voice." Use for taglines, signatures, mail subjects, anywhere warmth matters.
Sans for everything functional. Serif for everything emotional. When in doubt, default to DM Sans.

Section 05

Paste-Ready CSS

Drop this into the workbook

Everything needed to bootstrap the hierarchy on a new page. Copy, paste, build.

:root {
  --deep-blue-lake: #005B54;
  --deep-blue-lake-deep: #003D38;
  --ashes-brindle: #2D2D2D;
  --text: #2D2D2D;
  --text-light: #5A5A5A;
  --clarity-white: #ffffff;
  --kalkaska-mud: #EEF4F3;
}

body {
  font-family: 'DM Sans', -apple-system, sans-serif;
  font-size: 1rem;
  line-height: 1.65;
  color: var(--text);
  background: var(--kalkaska-mud);
  -webkit-font-smoothing: antialiased;
}

h1 {
  font-family: 'Libre Baskerville', serif;
  font-size: 3.6rem;
  font-weight: 700;
  line-height: 1.05;
  letter-spacing: -0.01em;
  color: var(--ashes-brindle);
}

h2 {
  font-family: 'Libre Baskerville', serif;
  font-size: 1.5rem;
  font-weight: 700;
  color: var(--ashes-brindle);
}

h3 {
  font-family: 'Libre Baskerville', serif;
  font-size: 1.1rem;
  font-weight: 700;
  color: var(--ashes-brindle);
}

.subhead {
  font-family: 'Libre Baskerville', serif;
  font-style: italic;
  font-size: 1.2rem;
  line-height: 1.4;
  color: var(--text-light);
}
